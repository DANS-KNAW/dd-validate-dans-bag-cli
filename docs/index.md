dd-validate-dans-bag-cli
=========================

Provides the `dans-bag-validate` command to interact with `dd-validate-dans-bag` service via its [REST API]{:target=_blank}.

SYNOPSIS
--------

```bash
dans-bag-validate [ -p <package-type> ] <bag-path>
```

For more information use:

```bash
dans-bag-validate --help
```

[REST API]: {{ validate_dans_bag_api }}
